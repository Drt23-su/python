git ls-files -i --exclude-standard -o este comando nos sirve en git para listar todos los archivos ignorados
Pasos para ignorar archivos en Git:
1. Crear o editar el archivo .gitignore
Si aún no tienes un archivo .gitignore en la raíz del repositorio, créalo.
Si ya existe, ábrelo con un editor de texto.


2. Añadir patrones de archivos y carpetas a ignorar
Dentro del .gitignore, agrega los nombres de los archivos o directorios que deseas excluir. Algunos ejemplos:

Ignorar archivos específicos:

archivo.txt
Ignorar todos los archivos de un tipo específico:

*.log # Ignora todos los archivos con extensión .log
Ignorar una carpeta completa:

/carpeta/
Ignorar todos los archivos en una subcarpeta:

/carpeta/*
Ignorar archivos temporales del sistema operativo (ejemplos para macOS y Windows):

.DS_Store # macOS Thumbs.db # Windows
Ignorar configuraciones específicas del entorno:

/node_modules/ # Para proyectos Node.js /venv/ # Para proyectos Python

3. Confirmar que los archivos están siendo ignorados
Para verificar si Git está ignorando correctamente un archivo, usa el comando:

git check-ignore -v nombre_del_archivo
